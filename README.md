# Systems-Analysis-Design-Opera-House-Management-System

Name :Marwan Mustafa Karam Taha ElMulla
Section: 1 on Sunday

A comprehensive management system for the Opera House. It enables administrators to manage musicians, albums, instruments, and studio recordings, while also handling opera shows, hall schedules, online ticket bookings, customer data, and payments. The system aims to centralize information, reduce manual errors, and improve the overall audience experience.
